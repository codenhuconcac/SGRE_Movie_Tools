# Steins;Gate Re:Boot Movie Tools

## Usage:
### To decrypt:
```text
python movie.py "game/example.webm" "decrypted/example.webm"
```
### To encrypt:
When encrypting, make sure you keep the original filename.
The filename is used to generate the encryption key.
```text
python movie.py "decrypted/example.webm" "encrypted/example.webm"
```
